Line-Based Placement Example

Header (spans lines 1-4)
Navigation (lines 1-2)
Main Content (lines 2-3)
Sidebar (lines 3-4)
Footer (spans lines 1-4)

Explanation

This layout shows how to use Line-Based Placement with CSS Grid. In this method, you position each section of the page by using the numbered grid lines that divide the rows and columns. Instead of naming parts of the grid, I used line numbers to tell where each element should go. For example, the header goes from line 1 to 4, which makes it stretch across all three columns. The navigation is placed in the first column, the main content goes in the middle column, and the sidebar is on the right. The footer also spans across the bottom, using the same grid line numbers as the header. This method is good when you want to be exact about where things go. It gives you a lot of control over how each section is placed. The only downside is that it can get a little confusing if your layout gets bigger, since you have to remember all the grid line numbers.
